# Pixel Million

A modern Million Dollar Homepage-inspired interactive advertising wall.

## MVP

- 1,000,000 pixel inventory
- Interactive ad wall
- Existing ad placements
- Random available-area selection demo
- Pricing at $1/pixel
- Purchase modal
- Responsive design
- $1,000,000 public revenue target

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
